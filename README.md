## Fitur
- Intro animasi pintu garasi terbuka, mobil sport muncul, progress loading 0–100%, tombol **START ENGINE** dan **SKIP INTRO**.
- Navigasi ke About, Hobbies, Playlist, Dream Garage, dan Contact.
- Kursor khusus menggunakan foto setir BMW pada perangkat desktop; perangkat sentuh tetap memakai kontrol normal.
- Galeri foto asli yang dikirim untuk proyek ini, dikelompokkan ke profil, traveling/alam, kegiatan musik, gaming, kuliner, dan otomotif.
- Layout responsif untuk desktop dan ponsel.

## Menjalankan website
Buka `index.html` di browser. Website tidak membutuhkan instalasi package. Koneksi internet diperlukan untuk memuat Google Fonts.

## Publikasi melalui GitHub Pages
1. Ekstrak ZIP ini.
2. Unggah isi folder `Garage` (folder `assets` beserta empat file utama) ke root repository GitHub.
3. Commit perubahan ke branch `main`.
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/(root)`, lalu klik **Save**.
6. Setelah deployment selesai, buka `https://rahenz.github.io/Garage/`.

## Catatan aset
Semua foto pada folder `assets` adalah berkas yang sebelumnya dikirim dalam percakapan. Foto mobil yang tersedia digunakan sebagai visual otomotif; foto tersebut bukan dokumentasi asli Nissan Skyline GT-R R34 atau BMW M4 secara spesifik. Nama file dan path gambar di HTML sudah disesuaikan dengan folder `assets`.

Website ini merupakan proyek personal nonresmi dan tidak berafiliasi dengan merek kendaraan maupun waralaba film yang menjadi inspirasi visual.
